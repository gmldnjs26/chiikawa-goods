## 0. 당신의 역할

정보 도구의 UI 디자인을 맡는다. 대상은 **캐릭터 굿즈 정보를 빠르게 확인하는 웹 화면**이다.
캐릭터를 다루지만 **UI는 캐릭터 굿즈처럼 보이면 안 된다.** 뉴스 리더 · 항공 출발 안내판 · 증권 앱처럼 "정보를 10초 안에 읽는 도구"로 만든다.
Apple Human Interface Guidelines(Clarity / Deference / Depth)를 기준으로 삼되, 그 위에 이 제품만의 시각 정체성을 하나 세운다.

산출물은 §12에 있다. 먼저 §1–§11을 전부 읽고 질문이 있으면 디자인에 들어가기 전에 물어라.

## 1. 제품 한 줄

> ちいかわ(치이카와) 공식 굿즈의 **발매 · 예약 · 재입고 정보**를 여러 공식 소스에서 모아, **상태(지금 살 수 있나)** 기준으로 정리해 보여주는 일본어 웹 서비스.

- **사용자**: 일본의 치이카와 팬. 스마트폰으로 본다. 대부분 검색으로 유입된다
- **핵심 질문 1개**: "지금 살 수 있는 게 뭐지? 곧 뭐가 열리지? 품절된 건 다시 나오나?"
- **성공 기준**: 첫 화면을 열고 **10초 안에** 위 질문에 답이 보인다
- **차별점 2개** (경쟁 팬 블로그가 못 하는 것):
  1. 상태 우선 타임라인 + 예약 개시 사전 감지
  2. **항목마다 출처 링크 명시** (팬 블로그들은 출처를 안 밝힌다)
- 비목표: 가격 비교 · 커뮤니티 · 검색 · 구매 대행 · 광고. 화면에 이런 요소를 넣지 않는다
- 수익 없음. 광고 슬롯 · 어필리에이트 배너 자리를 만들지 않는다

## 2. 디자인 원칙 (우선순위 순)

1. **상태와 날짜가 가장 먼저 읽힌다.** 장식이 정보를 밀어내지 않는다
2. **콘텐츠가 주인공.** 상품명 · 가격 · 상태 · 날짜. UI는 물러난다
3. **계층은 여백과 그룹핑으로.** 그림자 · 테두리 남발 금지
4. **색 단독으로 정보를 주지 않는다.** 뱃지에는 항상 텍스트가 같이 있다 (색약 대응)
5. **정직하게 표시한다.** 추정값은 추정이라고 보이게, 미판정은 미판정으로 보이게. 확정인 척하지 않는다
6. **품절을 하나로 뭉개지 않는다.** "재입고 예정 있음 / 미정 공지 / 정보 없음"은 유저 행동이 다르다(기다린다 / 판단 못 한다 / 포기한다). 시각적으로 구분되어야 한다

### 하지 않는 것

- 캐릭터 일러스트 · 캐릭터 색(치이카와 특유의 파스텔 핑크/하늘색)을 UI 요소로 쓰지 않는다. 저작물이고, 정보를 가린다
- **이모지를 아이콘으로 쓰지 않는다.** 현재 프로토타입이 🛒🏪🎯 같은 이모지를 쓰고 있고, 이것이 "조잡하다"는 평가의 주원인이다. 전용 아이콘 세트를 만든다 (§7)
- 그라데이션 · 네온 · 과한 그림자 · 카드마다 다른 둥근 정도
- 커스텀 스크롤바 · 커스텀 커서 · 스플래시 화면
- 숫자 마커(01/02/03), 섹션 구분용 이모지, 가운데 정렬 도배
- "AI가 만든 것 같은" 기본값 — 크림색 배경+세리프+테라코타, 검정+형광 초록, 보라-파랑 그라데이션 히어로, 모든 요소 `rounded-lg`

## 3. 정보 구조 — 화면 3개, 카드 1종

공통 프레임: 상단에 서비스명(가제) + **탭 3개**(ホーム / カレンダー / 過去・完売). 하단에 면책 푸터.
최대 너비 720px 정도의 단일 컬럼. 모바일 375px 우선, 데스크톱은 같은 레이아웃을 가운데 놓는다.

### 3.1 홈 — 상태 우선 3섹션

```
🟢 今すぐ買えるもの   (12)      ← 최상단. 지금 행동 가능한 것만. 최근 열린 순
🔜 もうすぐ           (5)       ← 8일 전 ~ 당일. 가까운 날짜 순
🔵 再入荷を待てるもの  (3)       ← 품절이지만 재입고가 "예고된" 것. 날짜 순, 시기만 아는 것은 뒤
```

- 섹션 제목의 🟢🔜🔵는 현재 이모지다. **아이콘 또는 색 마커로 대체**한다
- 각 섹션은 카드 목록. 섹션마다 건수 표시
- 섹션 2·3에는 한 줄 설명이 붙는다 (예: "開始時刻はサイトに記載がないため推定です")
- 섹션이 비면 빈 상태 문구 1줄 (예: "予定されている発表はありません")
- 섹션 위에 **필터** (§8)

### 3.2 캘린더 — 굿즈가 아니라 "사건"

굿즈 하나에 날짜가 3개 붙는다(예약일 / 발매일 / 재입고일). 그래서 **같은 굿즈가 캘린더에 두 번 나온다.** 유저가 두 번 행동해야 하므로 두 번 보여주는 것이 맞다.

```
2026年9月                              ← 달 이동 (전월 / 다음달)
────────────────────────────────
 6 (日) 今日
        公式オンライン
          発売      [ちいかわポケット] ちいかわポケット 第4弾   全10種
 9 (水)
        公式オンライン
          予約開始  [ちいかわマーケット] 秋の新作 12点    時刻は推定
13 (日)
        くじ
          発売      [一番くじ] 一番くじ ちいかわ ～秋のおでかけ～   全72種
15 (火)
        公式オンライン
          再入荷    [ちいかわマーケット] ふわふわクッション
```

- 날짜 → 그 안에서 **채널로 그룹** → 사건(予約開始 / 発売 / 再入荷) + 브랜드 라벨 + 상품명
- "오늘"은 눈에 띄게. 지난 날짜는 톤 다운
- 날짜가 확정된 사건만 놓는다. "9月下旬" 같은 폭이 있는 예고는 캘린더에 없다 (홈 목록에만)
- 시각(몇 시 오픈)은 데이터에 없다. 오늘 이후 사건에 "時刻は推定" 표시가 붙는다 — 확정값과 시각적으로 구분되어야 한다 (예: 점선 밑줄, 옅은 톤). 이 표시는 지난 날짜에는 붙지 않는다
- 목록 형식이 기본. 월 격자(달력 그리드)는 **아니다** — 하루에 사건이 0~5개라 격자는 비거나 넘친다

### 3.3 아카이브 — 過去 / 完売

- 품절이고 재입고 예고가 없는 것 + "재입고 미정"이라고 공지된 것
- 같은 카드, 최근 순. 아래에 "もっと見る" 버튼으로 30건씩 추가 로드 (무한 스크롤 아님)
- 로딩 중 / 마지막 페이지("これ以上はありません") / 실패("読み込みに失敗しました") 3상태

## 4. 카드 — 세 화면이 같은 카드를 쓴다

```
┌────────┐  [브랜드 칩]                          [상태 뱃지]
│ 이미지  │  상품명 (1~2줄, 링크)
│ 96×96  │  채널 · 지역 · 확정/랜덤(全N種) · [정보 칩…]        ¥2,970
└────────┘  (예정 줄: 9/9(水) 予約開始  9/19(土) 発売  時刻は推定)
            (보조 줄: 〜9/12(土) / 再入荷予定 9/15 / 再入荷は未定と告知)
            ─────────────────────────────────────────────
            出典: ちいかわマーケット (9/5 21:01 確認)        公式ページ →
```

### 필수 4요소 — 이 4개로 "내가 살 수 있는 물건인지"가 판정된다

| 요소 | 값 | 표기 |
| --- | --- | --- |
| **브랜드 칩** | ちいかわマーケット / ナガノマーケット / ちいかわポケット / もぐもぐ本舗 / 一番くじ / **미판정** | 미판정은 `その他`로 **보여준다.** 숨기지 않는다. 판정된 것과 시각적으로 구분(예: 점선 테두리) |
| **채널** | 7종 (§7) | 아이콘 + 라벨 |
| **지역** | オンライン / 全国 / 東京 / 大阪 / … | 텍스트 |
| **확정 / 랜덤** | 확정 구매 or 랜덤(블라인드 · くじ · 프라이즈) | 랜덤이면 `全8種`처럼 총 종류 수. 랜덤은 눈에 띄어야 한다 — "노려서 살 수 없다"는 정보 |

### 그 외

- **이미지**: 카드당 1장, 96×96 (플랜 v1.2에서 72→96으로 키움). **없을 수 있다** (현재 데이터 대부분 없음, 권리 문의 회신 전). 없으면 **자리만 비우고 카드는 그대로 선다.** 빈 자리가 "깨진" 게 아니라 "의도된 빈칸"으로 보여야 한다
- **가격**: `¥2,970`. 변형 간 가격이 다르면 `¥1,620〜`. 없으면 표시 안 함 (가격 자리에 "未定"을 쓰지 않는다)
- **정보 칩**: `川越店限定` 같은 부가 라벨. 지역 제약이 아니라 정보. 브랜드 칩과 같은 급이 아니어야 한다
- **출처**: 소스명 링크 + 마지막 확인 시각. **차별점이다.** 작게 두되 반드시 있다. 소스가 2개 이상일 수 있다
- **공식 페이지 링크**: 카드의 주 행동. 새 탭
- **품절(ENDED) 카드**: 톤 다운. 단, 재입고 예고가 있는 것은 "죽은 카드"로 보이면 안 된다
- 터치 타깃 44×44pt 이상. 카드 안에 링크가 3개(상품명 · 출처 · 공식)라 카드 전체를 링크로 만들지 않는다

## 5. 상태 뱃지 — 7종 + 판정 불가 1종

뱃지 = **상태 + 가장 가까운 예정**의 조합. 이 프로젝트에서 가장 중요한 UI 요소다.

| # | 뱃지 텍스트 | 의미 | 유저 행동 | 색 의미 |
| --- | --- | --- | --- | --- |
| 1 | 販売中 | 지금 살 수 있다 | 산다 | 판매중 (green 계열) |
| 2 | 再入荷 | 품절됐다가 **방금(3일 이내)** 다시 살 수 있게 됐다 | 서두른다 | 판매중 + 강조 |
| 3 | D-3 / 本日 | 예약 또는 발매가 곧 열린다 | 준비한다 | 예정 (orange 계열) |
| 4 | 再入荷 9/15 | 품절 + **날짜가 정해진** 재입고 예정 | 기다린다 | 재입고예정 (blue 계열) |
| 5 | 再入荷 9月下旬 | 품절 + **시기만** 공지된 재입고 예정 | 기다린다 | 재입고예정, 4보다 약하게 |
| 6 | 再入荷未定 | 품절 + "재입고 미정"이라고 공지됨 | 판단 못 한다 | 중립, 비어 있는 느낌(점선 등) |
| 7 | 完売 | 품절 + 재입고 정보 없음 | 포기한다 | 종료 (gray) |
| 8 | 判定不可 | 데이터 이상(예정이 중복). 드물다 | — | 경고. 숨기지 않고 드러낸다 |

- 상태색은 의미에 **고정**: 판매중=green, 예정=orange, 재입고예정=blue, 종료=gray. 4개뿐이고 늘리지 않는다
- 4·5·6·7은 전부 "품절"이지만 **한눈에 다르게** 보여야 한다. 이게 이 제품의 핵심 주장이다
- 뱃지 안의 🟢📦🔜🔵⚪️🔴 이모지는 현재 프로토타입 표기다. **대체하라.** 색 도트 · 아이콘 · 텍스트만 — 무엇이든 되지만 이모지는 아니다
- 다크모드에서 상태색은 채도를 낮춘다. 옅은 배경 + 같은 계열 텍스트 조합은 대비 4.5:1을 확인한다

## 7. 아이콘 세트 — 이모지 대체 (필수 산출물)

현재 이모지로 쓰이는 자리 전부를 대체하는 **단색 라인 아이콘 세트**. 16px · 20px에서 읽혀야 한다. 스타일 통일(선 굵기, 라운드, 시각 무게).

### 채널 7종

| 코드 | 라벨 | 의미 | 현재 이모지 |
| --- | --- | --- | --- |
| online_official | 公式オンライン | 공식 온라인 스토어. 집에서 클릭 | 🛒 |
| konbini | コンビニ | 편의점 | 🏪 |
| arcade | プライズ | 게임센터 크레인 게임 경품 | 🕹 |
| gacha | ガシャポン | 캡슐토이 | 🎰 |
| kuji | くじ | 제비뽑기(一番くじ 등). 오픈런 | 🎯 |
| store | 実店舗 | 팝업 · 상설 매장. 가야 한다 | 📍 |
| apparel | アパレル | 의류 콜라보 | 👕 |

채널은 "어떻게 손에 넣나"를 말한다 — 같은 발매일이라도 공식 EC는 집에서 클릭, 편의점은 아침에 가게, 프라이즈는 게임센터, くじ는 오픈런. 아이콘이 이 **행동의 차이**를 암시하면 좋다.

### 섹션 · 상태 마커

홈 섹션 3개(今すぐ / もうすぐ / 再入荷待ち), 아카이브(過去), 뱃지 8종에 쓸 마커. 색 도트만으로 해결해도 된다. 정하라.

### 기타

전월/다음달 화살표, 외부 링크, 더 보기, 체크박스. 기존 오픈소스 세트(Lucide · Phosphor · SF Symbols 스타일)를 기반으로 해도 된다 — 단 채널 7종은 이 제품 전용으로 그려야 한다.

## 8. 필터 (홈에만)

```
チャネル:  [公式オンライン] [コンビニ] [プライズ] [ガシャポン] [くじ] [実店舗] [アパレル]
ブランド:  [ちいかわマーケット] [ちいかわポケット] [もぐもぐ本舗] [一番くじ] [その他]
☐ ランダム商品を除く     ☐ オンラインで買えるものだけ
```

- 칩은 토글(복수 선택). 선택 상태가 명확히 보여야 한다
- 채널 칩은 응답에 있는 채널만, 브랜드 칩도 응답에 있는 브랜드만 나온다 (0~7개 · 0~6개)
- 체크박스 2개가 실제로 가장 많이 쓰인다 — "게임센터에 못 가는 사람"과 "랜덤은 싫은 사람"
- 브랜드 칩에 색을 주지 않는다. 브랜드까지 색이 붙으면 상태색이 안 보인다
- 필터는 즉시 반영(요청 없음). 결과 0건이면 섹션마다 빈 상태 문구

## 9. 시각 시스템 제약

### 타이포그래피

- **웹폰트를 로드하지 않는다.** 시스템 폰트 스택: `-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", sans-serif`. 일본어 웹폰트는 수 MB라 초기 표시가 늦다. 이 제약 안에서 타이포 계층을 만든다
  - 예외를 주장하려면 (예: 숫자·라틴만 웹폰트) 근거와 용량을 같이 제시하라
- 일본어는 라틴보다 시각적으로 커 보인다. 본문 15–16px. 자간을 넓히지 않는다
- 한 화면에 크기 4단계까지. 굵기만으로 계층을 만들지 않는다
- 숫자(가격 · 날짜 · 건수)는 `tabular-nums`

### 색

- 시맨틱 토큰으로 정의한다. 라이트/다크 둘 다. 현재 토큰 이름(유지 권장):
  `background · surface · fill · separator · label · label-secondary · label-tertiary · accent · on-sale · upcoming · restock · ended`
- 액센트는 **1색**. 상태색 4개와 충돌하지 않는 색
- 회색은 "고른" 회색 — 액센트 쪽으로 살짝 기운 중립색. 순수 #808080 계열 금지
- 다크에서 순수 검정(#000) 배경 금지
- 본문 대비 4.5:1 이상

### 간격 · 형태

- 4pt 배수. 인접 요소 4–8, 그룹 사이 16–24, 섹션 사이 32
- 목록은 iOS inset grouped list가 기준 — 카드를 개별 상자로 흩뿌리지 않고, 섹션으로 묶고 안에서 구분선으로 나눈다
- 테두리 · 채움 · 라운드 · 그림자는 "별개의 객체"라는 신호다. 역할이 있는 곳에만 쓴다

### 모션

- 상태 변화(로딩 → 표시, 필터 토글)에만. 장식 모션 없음. `prefers-reduced-motion` 존중

## 10. 카피 (일본어)

- 서비스 언어는 일본어. 팬덤 말투가 있으므로 사무적 표기로 도배하지 않되, 캐릭터 말투 흉내도 내지 않는다
- 현재 문안은 전부 임시안. 디자인 안에서 문안을 다듬어 제안해도 된다 (특히 섹션 제목 · 빈 상태 · 푸터)
- 현재 문안:
  - 섹션: `今すぐ買えるもの` / `もうすぐ` / `再入荷を待てるもの` / `過去 / 完売`
  - 섹션 설명: `8日前から当日まで。開始時刻はサイトに記載がないため推定です。日付のみ確定情報。` / `品切れですが再入荷が告知されています。時期のみの告知はそのまま表示します。`
  - 빈 상태: `条件に合う商品がありません` / `予定されている発表はありません` / `再入荷予定の告知はありません` / `この期間に予定はありません` / `該当なし`
  - 버튼: `もっと見る` / `読み込み中…` / `これ以上はありません` / `もう一度試す`
  - 푸터: `掲載情報は各公式サイトの公開情報をもとにした集計です。商品名・価格・日付・リンクのみを扱い、説明文は転載しません。` / `各項目に出典を明記しています。誤り・削除のご依頼は GitHub Issues まで。`
- 서비스명은 미정(가제 `ちいかわグッズ タイムライン`). 로고 · 워드마크는 이번 범위 밖. 텍스트 제목으로 둔다

## 12. 산출물

3. **디자인 토큰 표**: 색(§9 토큰명 유지) · 간격 · 라운드 · 타이포. Tailwind 4 `@theme`에 옮길 수 있는 형태 (CSS 변수명 + 값)
4. **아이콘 세트 SVG**: 채널 7종 + 섹션/상태 마커 + 유틸 (§7). 16/20px, currentColor, 단일 path 선호
5. **컴포넌트 명세**: 카드 · 뱃지 8종 · 칩(브랜드/정보/필터) · 섹션 헤더 · 캘린더 일자 행 · 탭 · 버튼. 각각 상태(기본/선택/비활성/포커스)

## 13. 현재 화면의 문제 (참고 — 이걸 고치려고 의뢰한다)

- 이모지가 아이콘 · 섹션 마커 · 뱃지에 전부 쓰여 조잡하다
- 시각 정체성이 없다. iOS 기본 회색 배경 + 파란 액센트 그대로
- 카드 안 정보 밀도는 맞지만 위계가 약하다 — 뱃지 · 가격 · 상품명이 같은 무게로 보인다
- 품절 4종(4·5·6·7)의 구분이 약하다
- 빈 이미지 자리가 "깨진 것"처럼 보인다
- 캘린더의 날짜 숫자 · 사건 · 상품명 위계가 평평하다

구현은 Next.js + Tailwind 4이고 개발자가 토큰 · 컴포넌트 명세를 직접 옮긴다. 개발 가능성보다 **정보 설계와 시각 정체성**에 집중하라. 단 §9 제약(웹폰트 없음, 토큰 4상태색)은 지킨다.
