7c · 규칙
묶음 키
날짜 + kind + 채널 + 브랜드. 시리즈는 키가 아니다 — 한 발표 안에 시리즈가 섞여서 키에 넣으면 발표가 갈라진다 (read-api §4.0)
접힌 행
브랜드 칩 · 날짜 kind / 「発売 N点」 + 셰브론 / 대표 이미지 44px 최대 4장 + 「+N」 점선 칸. 이미지는 items 순서대로 imageUrl 있는 것만
펼침
<details>. 셰브론 180° 회전. 소그룹 = series[0]. 순서는 건수 내림차순, 시리즈 없는 것은 その他로 마지막 · 점선 칩
소그룹 행
상품명(링크) … 가격. 14px. 全N種는 상품명 옆
카드
시리즈는 정보칩(labels)과 같은 자리, 앞에. 「映画ちいかわ」
홈
홈은 접지 않는다. 카드 전부 평평하게 — 카드가 이미지 · 뱃지 · 가격 · 날짜를 각자 갖고 있어 발표로 접으면 그 정보가 숨는다. 발표 단위는 캘린더의 몫
색
시리즈 칩은 무채(선). 색은 상태색 레일만 — 시리즈에 색을 주면 상태색이 안 보인다

대비 규칙
캐릭터 색은 전부 밝아서 텍스트로 쓰면 4.5:1이 안 된다. 그래서 뱃지 텍스트는 항상 먹(#2A2225), 색은 배경 틴트 · 도트 · 레일에만 얹는다. 색약 대응은 텍스트가 담당(브리프 원칙 4).
채움/틴트
강조 뱃지(再入荷·本日)는 원색 채움 + 먹 텍스트, 일반 뱃지는 틴트 채움 + 먹 텍스트 + 원색 도트. 시기만 아는 再入荷 9月下旬는 틴트 + 점선 테두리.
1b 대비 바뀐 것
桜 팔레트
background #FCF7F7 (거의 흰 벚꽃), surface #FFFFFF, label #2A2225 (분홍 쪽으로 기운 먹), label-secondary #6B5A5F, separator #EFE1E4. 액센트 #C8484A 연한 빨강 (배경 대비 4.6:1) — 링크·탭 밑줄·선택 칩·체크박스 4곳만. 상태색 green/orange/blue/gray는 고정. 브리프 §2 "캐릭터 색 금지"는 의뢰인 요청으로 완화: 배경은 거의 흰색에 머물고 핑크는 기운 정도로만.
손그림 선
상태 레일·구분선·탭 인디케이터가 살짝 흔들리는 2.5px 라운드 선. 섹션 마커는 lucide 아이콘 22px stroke 2(今すぐ ShoppingBag · もうすぐ CalendarClock · 再入荷 PackageOpen · 過去 Archive)를 상태색으로 — 코드의 Section.tsx와 동일. 손그림 원은 뺐다(2026-09-07). 기계적 직선을 전부 뺐다.
숫자 폰트
Klee One 600, 숫자·¥·/·()·〜·D 만 서브셋(약 6KB). 가격 18px, 건수 18px, 날짜. 일본어 본문은 시스템 폰트 그대로.
여백 위 작은 존재
이미지 112×112, 카드 패딩 14. 빈 자리는 종이색 위 이니셜 하나. 그룹 라운드 14.
선택 상태
필터 칩 선택 = 움버 1.5px 선 + 8% 틴트. 체크박스와 같은 색이라 "선택됨 = 움버" 하나로 통일. 검정 채움은 상태 뱃지보다 무거워져서 뺐다. 체크 아이콘도 없음.
형태
칩·뱃지는 pill(999). 뱃지는 채움 대신 1.5px 선 + 도트, 再入荷만 채움. 선이 곧 정체성이라 채움을 아낀다.
문안
섹션 설명을 구어로. 「サイトに載っていないので推定です」「品切れですが、再入荷が告知されています」.
이미지

4c · 아카이브 규칙
품절 카드 3종의 톤
完売 (7)
카드 전체 톤 다운: 상품명·가격 label-tertiary(#8E8982), 브랜드 칩·이미지 이니셜·출처 한 단계 옅게, 레일 separator 색. 뱃지는 fill 배경 + 회색 도트. "죽은 카드"가 맞다.
再入荷未定 (6)
톤 다운 없음. 점선 레일 + 점선 뱃지 + 점선 링 도트. 보조 줄 再入荷は未定と告知. 홈 3섹션에는 없고 아카이브에만 있다.
判定不可 (8)
톤 다운 없음. upcoming 색 삼각 마커 + 테두리 뱃지, 레일 upcoming. 보조 줄 予定が重複しています · 報告(Issues 링크). 숨기지 않는다.
全N種 (완판)
랜덤 라벨도 같이 옅어진다. 정보는 남고 강조만 빠진다.
정렬·건수
