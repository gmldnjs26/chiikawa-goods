날짜 열

사건 열
56px 고정. 予約開始=upcoming, 発売=on-sale, 再入荷=restock 색 텍스트 + 같은 색 2px 레일. 홈 카드의 레일과 같은 문법. 지난 날짜는 레일·텍스트 모두 회색.
상품 열
브랜드 12 회색 → 상품명 16/600 → 메타 14(全N種 · 時刻は推定). 상품명이 링크(공식 페이지 새 탭). 채널 라벨은 12/600 회색으로 사건 위에 한 번만.
時刻は推定
오늘 이후 사건에만, 점선 밑줄. 지난 날짜(9/2)에는 없다. 一番くじ(9/13)는 시각 추정 플래그가 false라 없음.

秋の新作 12点이 9/9 予約開始 · 9/19 発売로 두 번 등장. 의도된 것. 표기는 각각 다른 사건 색.
달 이동
‹ › 44×44 탭. 헤더 2026年9月에만 연도. 사건 없는 달은 この期間に予定はありません 1줄.

2b · 섹션 헤더 → 전용 목록
홈 헤더 링크 규칙
탭 타깃
헤더 행 전체(높이 44pt). 도트 · 제목 · 건수 · 오른쪽 すべて ›. 색은 label, 눌림 시 fill 배경.
URL
/now · /soon · /restock. 검색 유입 랜딩 가능.
홈 노출
섹션당 최대 5건. 6건 이상이면 헤더 링크가 전체를 연다. 5건 이하면 すべて ›를 숨기고 헤더는 정적.
전용 페이지
탭 바 없음. ‹ ホーム 뒤로가기 + 같은 헤더(도트·제목·건수) + 1줄 설명. 필터는 홈과 동일한 채널·브랜드 칩 + 체크박스 2개. 상태 필터는 없다(이미 상태로 들어왔으므로).
페이지네이션
아카이브와 같은 もっと見る 30건, 남은 건수 표기. 3상태(読み込み中… / これ以上はありません / もう一度試す) 공유.
빈 상태
필터 결과 0건: 条件に合う商品がありません + フィルターを解除 링크.
再入荷 뱃지
변형 2는 판매중 계열의 유일한 채움 뱃지(on-sale 배경 + 백색 텍스트). 3일이 지나면 販売中 틴트로 자동 강하.
1a · 디자인 플랜
ちいかわグッズ タイムライン — 디자인 플랜
v1.1 · 2026-09-06 (5 테마 전환 추가)
레이아웃 콘셉트
공항 출발 안내판처럼 모든 행이 같은 열 구조를 갖는다: 왼쪽 2px 상태 레일 → 날짜/카운트다운 열 → 상품 열 → 가격. 상태는 레일 색 + 뱃지 텍스트로 이중 표기되고, 카드는 개별 상자가 아니라 섹션 안의 한 행이다.
장식 요소는 0. 위계는 크기 4단계 · 회색 3단계 · 여백만으로 만들고, 액센트(움버)는 링크·탭 인디케이터·필터 선택 3곳에만 쓴다.
이 제품에만 있는 디테일
"불확실성 표기 문법" — 확정은 실선, 추정은 점선. 브랜드 미판정 칩(その他)은 점선 테두리, 시각 추정(時刻は推定)은 점선 밑줄, 再入荷未定 뱃지는 점선 링 마커, 시기만 아는 再入荷 9月下旬은 반투명 채움. 유저는 "점선 = 아직 모르는 것"을 한 번 배우면 화면 전체에서 읽는다. 팬 블로그가 못 하는 정직한 표시가 시각 정체성이 된다.

5b · 테마 전환 규칙 (v1.1 · 2026-09-06 추가)
라이트 / 다크 전환
위치
헤더 우측, 서비스명과 같은 행. 탭 바 위. 섹션 전용 페이지(/now 등)에도 있다.
버튼
36×36, 라운드 6px, 1px border 테두리, surface 채움, 아이콘 label 색. 호버 fill. 아이콘 lucide Sun(지금 라이트) / Moon(지금 다크), 1.2rem, stroke 2. 텍스트 라벨 없음 — aria-label만.
상태
2상태(라이트 ↔ 다크). 저장값 없으면 OS를 따르고 아이콘은 지금 보이는 테마 기준. 저장은 localStorage, 첫 페인트 전 <html data-theme>에 찍어 깜빡임 없음.
전환 모션
클릭 지점에서 원이 퍼지며 새 테마가 드러난다 — View Transitions API, ::view-transition-new(root)에 clip-path: circle(0 → 화면 대각선) 500ms ease-in-out. 기본 크로스페이드는 끈다. 옛 화면은 아래에 그대로. 유일한 장식성 모션이고 「상태 변화」에 해당한다.
줄임 · 미지원
prefers-reduced-motion이거나 View Transition 미지원이면 즉시 전환. 기능은 같다.
토큰
라이트 · 다크 팔레트는 1a 그대로. color-scheme도 같이 바뀐다(폼 컨트롤 · 스크롤바). 새 토큰 없음.
참고
